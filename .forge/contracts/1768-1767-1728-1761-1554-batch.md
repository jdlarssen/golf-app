1. **Kald kompilering** (e2e/global-setup.ts `probeHealth`): ved

   først når retryen også feiler → `unusable`. Andre transportfeil beholder
   dagens semantikk. Kommentar: kald Turbopack-kompilering av /api/health på
   fersk `npm run dev` kan sprenge 3s (CI kjører `next start`, prekompilert
   og upåvirket).
2. **sha-grenen** (lib/serverIdentity/assess.ts): sha-mismatch feiler KUN når
   `local.headMtimeMs === null` (bootedAt-grenen degradert). Med lesbar
   HEAD-mtime og `bootedAt >= headMtimeMs` er sha-avvik et stale
   førstekalls-stempel etter en ren `git commit` (arbeidstreet er identisk)
   → match. Oppdater funksjonens doc-kommentar (rekkefølge-resonnementet);
   mismatch-koden `'sha'` beholdes for degradert-leg-tilfellet.
3. **Tester** (lib/serverIdentity/assess.test.ts): rød-før-grønn for de nye
   radene: (a) sha-avvik + lesbar mtime + bootedAt ≥ mtime → match; (b)
   sha-avvik + `headMtimeMs: null` → mismatch `'sha'`; (c) grensetilfellet
   `bootedAt === headMtimeMs` → match. Eksisterende rader justeres kun der
   oppførselen bevisst endres — cwd- og booted-before-checkout-radene skal
   være uendret.
